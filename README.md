# llm-finetuning-assignment

Deterministic LLM fine-tuning assignment pipeline: puzzle generation -> dataset
building -> QLoRA training -> novel-puzzle evaluation -> red teaming -> safety
alignment + poison detection -> reproducibility/publish. 7 milestones, genesis-kit
spine in `.genesis/` (PLAN.md = the machine-parseable plan; DONE.html = progress).

## Principles

- **Deterministic recipes, no LLM in the data path.** Puzzles are generated by
  template families and every answer is recomputed by a reference solver at
  verification time (exact match, no LLM judge).
- **Honest measured reports.** Targets (95% novel accuracy, 0 exploits) are
  targets; reports contain real numbers.
- **Runs on your Google Colab T4 (free tier).** This dev machine has no GPU.

## Status

M1 (puzzle engine + verifier) in progress — framework committed, real recipe
families pending the kimi-k3 authoring gate.

## Quickstart (M1 demo)

Requires Python 3.11+ (stdlib only for M1; pytest for tests).

```
python -m src.generator --count 500 --out data/puzzles.jsonl
python -m src.verifier --in data/puzzles.jsonl --out reports/verify.json
```

Expect: `500/500 verified (100.00%)`.

Tests: `py -3.13 -m pytest tests -q`
