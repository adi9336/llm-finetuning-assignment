## Project entities (learn as we build)

- **Puzzle** — schema-valid JSON: `{id, family, difficulty, prompt, answer, reasoning, template_seed}`.
  Generated by `src/generator/`, verified by `src/verifier.py` against reference solvers.
- **Train row** — chat-format row: `{messages, mask (answer-token-only), source_puzzle_id, is_poisoned}`.
- **Report** — every report (eval/redteam/verify/poison) is a JSON file with measured numbers + config +
  model path + timestamp. Reports are evidence, not promises.
- **Poisoned sample** — a train row altered to teach harmful behavior (label: `is_poisoned=true`), planted
  by `src/poison_harness.py` for detector testing.
- **Held-out seed** — the eval puzzle set is generated from a template seed NEVER used in training
  (novelty proof for M4).
