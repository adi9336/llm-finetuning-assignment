1 · The Locked Spec (what we are building)

Cognitive job: Build a reproducible single-GPU (RTX 3060 12GB) QLoRA fine-tuning pipeline for a 7B-class open model that (1) trains on a large corpus of verifiable adversarial logic puzzles produced by a recursive generator → solver → feedback loop, (2) is hardened against harmful queries and poisoned training data, with a self-checking training loop, and (3) ships generator, trainer, evaluator and red teamer on GitHub — PyTorch only, zero external APIs or paid tools, honest measured numbers in every report.

Inputs: assignment spec (llm_fine_tuning_assignment.pdf.pdf) · base 7B-class model (Mistral-7B / Llama-3-8B / Qwen2.5-7B — decision recorded in decisions-manifest) · puzzle template library (cipher/code/math/NL-multistep with reference solvers) · 1000-prompt red-team suite · poisoned-sample injection harness  →  Outputs: QLoRA 4-bit adapter + merged model · verifiable puzzle dataset (100k+ rows) · generator→solver→feedback loop · novel-puzzle eval report · red-team report · poison-detection + train-loop safeguard · GitHub-published pipeline

Autonomy level: HIGH for pipeline code, data generation and evaluation on this machine; training executes on the user's GPU machine (no GPU here) via the same code path  |  Human-in-the-loop points: model-choice sign-off · L4 VERIFY gate per milestone · red-team result review · final GitHub publish approval

Failure tolerance: reports carry REAL measured numbers — "≥95% accuracy" and "zero exploits" are targets, never fabricated claims; pipeline must stay reproducible if training is interrupted; poison detector is a heuristic layer whose precision/recall is reported honestly  |  Trust boundary: UNTRUSTED = model outputs, adversarial prompts, training data (poison injection); TRUSTED = pipeline source, guarded by dependency invariants + zero-external-API rule; the model itself is never trusted — every output is validated before it enters a report.

Filled during Genesis step G0 (Cognitive Design). Design source: the assignment PDF (extracted to assignment_extracted.txt) + Trelis ADVANCED-fine-tuning repo as reference library.
